## DESCRIPTION
- This project implements a basic speech-to-text system using Python and pre-trained speech recognition models. It converts short audio clips into text, demonstrating a simple and practical application of AI in speech processing without training a model from scratch.


## Features
- Converts spoken audio into text
- Uses pre-trained speech recognition models
- Supports short WAV audio clips
- Simple and beginner-friendly implementation

## Technologies Used
- Python
- SpeechRecognition Library
- Google Speech Recognition API

## Installation
1. Clone the repository:
   - git clone https://github.com/riyarozario/speech-to-text.git
   - cd speech-to-text

2. Install the required dependencies:

  - pip install -r requirements.txt

3. Add a WAV audio file named audio.wav to the project folder.

4. Run the program:
    - python speech_to_text.py
